HARU fabrique ses films avec FFmpeg, un logiciel libre distribué sous la GNU Lesser General Public License 3.0 ou ultérieure (LGPL). HARU lui-même n'est pas open source ; la LGPL lui permet d'utiliser FFmpeg à ces conditions. Voici le code source complet des bibliothèques FFmpeg présentes dans HARU, et la façon de les compiler.

Ce que HARU embarque

HARU 1.0.45 et versions suivantes, sur Android et iPhone : FFmpeg 8.1.2, compilé par FFmpegKit sous forme de bibliothèques partagées distinctes (libavcodec, libavdevice, libavfilter, libavformat, libavutil, libswresample, libswscale et ffmpegkit). La compilation « min » : aucune partie GPL ni non libre. FFmpeg n'est pas modifié.

Compiler les bibliothèques vous-même

Décompressez l'archive FFmpegKit et lancez ./build-all.sh android min ou ./build-all.sh ios min (Android NDK 29.0.13113456, Xcode avec le SDK iOS). Les scripts récupèrent FFmpeg 8.1.2 et cpu_features aux mêmes tags que les archives ci-dessus ; la configuration exacte de FFmpeg est affichée par les bibliothèques elles-mêmes (avutil_configuration()). La compilation prend des heures et demande la chaîne d'outils complète.

Utiliser votre propre compilation

Les bibliothèques sont des fichiers distincts dans l'app : lib/<abi>/lib*.so sur Android, Frameworks/*.framework sur iPhone. Vous pouvez les remplacer par votre propre compilation de FFmpeg 8.1.2 ou d'une version compatible. S'il vous faut autre chose de notre part pour le faire, écrivez-nous.
