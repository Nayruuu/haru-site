FFmpeg in HARU · 17 November 2026

HARU makes its films with FFmpeg, which is free software licensed under the GNU Lesser General Public License 3.0 or later (LGPL). HARU itself is not open source; the LGPL lets it use FFmpeg on these terms. Here is the complete source code of the FFmpeg libraries in HARU, and how to build them.

What HARU carries

HARU 1.0.45 and later, on Android and iPhone: FFmpeg 8.1.2, built by FFmpegKit as separate shared libraries (libavcodec, libavdevice, libavfilter, libavformat, libavutil, libswresample, libswscale and ffmpegkit). The “min” build: no GPL or non-free part. FFmpeg is not modified.

Build the libraries yourself

Unpack the FFmpegKit archive and run ./build-all.sh android min or ./build-all.sh ios min (Android NDK 29.0.13113456, Xcode with the iOS SDK). The scripts fetch FFmpeg 8.1.2 and cpu_features from the same tags as the archives above; the exact FFmpeg configuration is printed by the libraries themselves (avutil_configuration()). The build takes hours and needs the full toolchain.

Use your own build

The libraries are separate files inside the app: lib/<abi>/lib*.so on Android, Frameworks/*.framework on iPhone. You may replace them with your own build of FFmpeg 8.1.2 or a compatible version. If you need anything else from us to do so, write to us.
